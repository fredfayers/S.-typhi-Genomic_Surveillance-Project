# Genomic Surveillance of S. Typhi Across Southeast Asia

A genotyping and AMR surveillance analysis of Salmonella Typhi genomes from Vietnam, Cambodia, Thailand and Laos, using the GenoTyphi scheme and Pathogenwatch.

## Background
Typhoid fever remains a public health concern in SE Asia, with rising antimicrobial resistance (AMR) shaping vaccine rollout decisions. This project asks: How do S. Typhi lineages and AMR determinants differ across Vietnam, Cambodia, Thailand and Laos, and what does that suggest for typhoid conjugate vaccine (TCV) targeting in the region?
